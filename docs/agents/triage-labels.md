# Triage Labels

This repository uses the canonical triage label vocabulary:

- `needs-triage`: Newly submitted issue awaiting triage classification.
- `needs-info`: Requires additional input, logs, or reproduction steps from reporter.
- `ready-for-agent`: Fully specified and ready for an automated subagent or coding flow.
- `ready-for-human`: Requires manual review, account access, or architectural signoff.
- `wontfix`: Acknowledged but out of scope or rejected.
