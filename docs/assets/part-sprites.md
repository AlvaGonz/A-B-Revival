# Part sprites: in-game mount art vs shop thumbnails

Generated by `Tools/A&B Revival/Regenerate Sprites and Atlases` from the frozen SWF. Vargames (2011) owns the original art.

`PartMounts/` is the in-game frame-0 art at 2x (nose-up). `Parts/` is the shop icon canvas at 1x. The machine-readable tables are `Assets/Resources/Data/PartMounts.txt` and `BulletSprites.txt`.

Marker grammar (`MC2F4Data.readMcData`): `H_<lr>_<types>` sockets, `F` muzzles, `L` child link points and `P` engine exhaust points. Coordinates are converted from twips/Y-down art space to stage pixels/Y-up in one place. The frozen part catalog has no `rot` value, so every placement rotation is 0; a marker with a rotation or scale is rejected by the extractor instead of being guessed. If a socket is missing, the runtime uses the documented category fallback (wings outboard, engines aft, guns forward) and never silently centres the child.

One row per shared SWF symbol; `PartMounts.txt` lists every catalog part id, including the left/right `lr` variants that share the same mount art.
